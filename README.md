# 大道國中平日中午加班申請表

可直接在瀏覽器填寫的靜態網頁。支援民國年度及月份輸入、10 筆加班紀錄、瀏覽器本機儲存及 A4 橫式列印／另存 PDF。

## 使用方式
開啟 GitHub Pages 網站，填寫資料後按「匯出 PDF／列印」，在列印視窗選擇「另存為 PDF」，紙張 A4、橫向，建議關閉頁首頁尾。

## 隱私
表單內容只儲存在使用者的瀏覽器 localStorage，不會傳送到 GitHub 或伺服器。共用電腦使用後請清空資料。

## 部署
GitHub repository Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
